# Скриншоты для README

Файлы отсюда подставляются в `README.md` и `README_RU.md`. Снимать при
работающем контейнере с добавленной подпиской; перед съёмкой убедиться, что в
кадр не попали реальный URL подписки, адреса серверов и логины.

| Файл | Что должно быть в кадре |
|---|---|
| `subscriptions.png` | Страница «Подписки»: карточка подписки со списком конфигураций и результатами HTTP-проверки |
| `subscription-editor.png` | Редактор подписки: URL, интервал, таймаут, заголовки профиля |
| `runtime-json.png` | Модальное окно «Конфигурация запуска» с подсветкой JSON |
| `settings-traffic.png` | Настройки → «Входящий трафик»: режимы перехвата и порты |
| `settings-xray.png` | Настройки → «Ядро Xray»: журнал, вырезание входов, локальные SOCKS и HTTP |
| `settings-headers.png` | Настройки → «Заголовки»: список с галочками отправки |
| `settings-geodata.png` | Настройки → «Geodata»: хранилище и состояние файлов |
| `settings-appearance.png` | Настройки → «Оформление»: темы и акцентный цвет |
