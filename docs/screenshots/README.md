# Скриншоты для README

Файлы отсюда подставляются в `README.md` и `README_RU.md`. Снимать при
работающем контейнере с добавленной подпиской; перед съёмкой убедиться, что в
кадр не попали реальный URL подписки, адреса серверов и логины.

| Файл | Что должно быть в кадре |
|---|---|
| `subscriptions.png` | Страница «Подписки»: карточка со списком конфигураций, результатами HTTP-проверки, трафиком и сроком действия |
| `subscription-editor.png` | Редактор подписки: URL, интервал, таймаут, данные из заголовков ответа |
| `runtime-json.png` | «Конфигурация запуска»: подсветка JSON и метки того, что контейнер добавил, заменил и оставил |
| `core-log.png` | «Журнал ядра»: вывод `xray run` из оперативной памяти |
| `settings-traffic.png` | Настройки → «Входящий трафик»: режимы перехвата и порты |
| `settings-network.png` | Настройки → «Сеть Alpine»: qdisc, conntrack и TCP-тюнинг со статусами sysctl |
| `settings-xray.png` | Настройки → «Ядро Xray»: журнал, sniffing и параметры HTTP-проверки |
| `settings-overrides.png` | Настройки → «Оверрайды»: DNS, outbounds, правила маршрутизации и кнопка проверки |
| `settings-inbounds.png` | Настройки → «Локальные входы»: SOCKS и HTTP контейнера |
| `settings-headers.png` | Настройки → «Заголовки»: список с галочками отправки |
| `settings-geodata.png` | Настройки → «Geodata»: хранилище и состояние файлов |
| `settings-appearance.png` | Настройки → «Оформление»: темы и акцентный цвет |

Снимаются в headless Chrome с шириной окна 1360 px, на контейнере, поднятом с
`BASIC_AUTH=off`: fetch из панели не работает, когда логин и пароль стоят в
самом URL, а другого способа пройти Basic Auth у headless-режима нет.
