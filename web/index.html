Исходная конфигурация сохраняется

Выбранный полный JSON остаётся отдельным файлом без изменений. Рядом создаются локальные фрагменты входящего трафика RouterOS, уровня журнала и geodata, необходимые контейнеру.

Файлы Geodata

Хранилище GeoIP и GeoSite для выбранной конфигурации

Обновляет файлы само ядро

Параметры geodata выбранного полного JSON сохраняются. Если раздела нет, geoip.dat и geosite.dat от Loyalsoldier добавляются, только когда конфигурация где-то ссылается на geoip: или geosite: — иначе качать двадцать семь мегабайт незачем. Xray скачивает свежие версии сам по своему cron, через собственный outbound, и перечитывает их без перезапуска. Контейнер только создаёт недостающие файлы перед стартом: без них ядро не принимает конфигурацию.

Geodata хранится в оперативной памяти

Файлы в /dev/shm исчезнут при перезапуске контейнера и будут скачаны заново до проверки конфигурации и запуска Xray.
